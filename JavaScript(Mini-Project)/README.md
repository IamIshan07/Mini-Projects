# 🚀 JavaScript Mini Projects

A collection of mini projects built using **HTML, CSS, and JavaScript** while learning web development.

These projects focus on strengthening JavaScript fundamentals, understanding DOM manipulation, handling user interactions, and developing problem-solving skills through practical implementation.

---

## 📂 Projects

### 1. 🎮 Simon Game

A memory-based game where players repeat an increasingly long sequence of colored buttons.

**Features:**
- Interactive color buttons
- Level-based gameplay
- Random sequence generation
- User input validation
- Game Over detection
- Increasing difficulty with each level

**Concepts Practiced:**
- DOM Manipulation
- Event Listeners
- Arrays
- Conditional Statements
- Random Number Generation
- Functions
- Game State Management
- Timeouts and Asynchronous Behavior

---

### 2. ✅ To-Do List

A simple task management application that allows users to manage their daily tasks.

**Features:**
- Add new tasks
- View the task list
- Mark tasks as completed
- Delete tasks

**Concepts Practiced:**
- DOM Manipulation
- Event Handling
- JavaScript Functions
- Arrays
- Creating and Removing HTML Elements
- Updating the DOM Dynamically

*Note: Features may vary depending on the current implementation.*

---

## 🛠️ Technologies Used

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Navigate to the desired mini-project.
4. Open its `index.html` file in your browser, or use the Live Server extension.

No additional dependencies are required.
