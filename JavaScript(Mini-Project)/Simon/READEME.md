# 🎮 Simon Game

A browser-based Simon Game built using **HTML, CSS, and JavaScript**. The game tests your memory by challenging you to remember and repeat an increasingly long sequence of colors.

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and game logic.

---

## 🚀 Features

- 🎨 Interactive color buttons
- 🔢 Increasing difficulty with each level
- 🧠 Memory-based gameplay
- ⌨️ Keyboard interaction to start the game
- ⚡ Real-time user input and sequence checking
- ❌ Game Over detection
- 🔄 Restart and play again

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

---

## 🎯 How to Play

1. Open the game in your browser.
2. Press any key to start the game.
3. Watch the color sequence carefully.
4. Repeat the sequence by clicking the colored buttons in the same order.
5. Each successful round increases the level and adds another step to the sequence.
6. If you select the wrong button, the game ends.
7. Start again and try to beat your previous level!
